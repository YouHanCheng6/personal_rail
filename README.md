# 沿线 · Personal Rail

**把时间、花费与换乘放在一起，选一趟更适合自己的车。**

![沿线 · 晨雾列车主题插画](personal_rail/static/images/morning-train.webp)

沿线是一个开源的铁路行程比较工具。在浏览器里选择路线和日期，即可查看公开行程资料，对比铁路耗时、席别参考价、换乘安排和预计舒适度。你也可以接入自己的大模型，让它根据候选方案给出推荐。

Python 后端 + 原生 HTML/CSS/JavaScript，无需 Node.js、数据库或 DeerFlow。下载后在自己的电脑上运行，通过浏览器使用。

[快速开始](#快速开始) · [接入大模型](#接入大模型) · [常见问题](#常见问题) · [参与开发](#参与开发)

## 可以做什么

- **按日期查询**：读取公开路线页面，核对日期和实际到发站，展示直达及来源提供的一次换乘方案。
- **多维度比较**：按综合、时间、铁路参考价或预计舒适度排序，最多同时对比 3 个方案。
- **按偏好筛选**：设置席别取向、铁路预算、同站换乘及最短换乘时间。
- **可选 AI 推荐**：使用你配置的模型在已有候选中做取舍；未配置模型也能正常查询、排序和比较。
- **来源可查**：展开行程查看分段时刻、席别价格、参考日期和原文链接，支持 JSON 导出。
- **官方公告**：展示近期 12306 公告，区分发布日期与读取时间。

### 当前支持的路线

| 路线 | 方向 |
| --- | --- |
| 龙川西 ↔ 北京 | 双向 |
| 北京 ↔ 赣州 | 双向 |
| 揭阳机场站 ↔ 龙川西 | 双向 |

目前是固定路线版本，暂不支持任意城市搜索。结果保留实际到发站：北京可能涉及不同车站，赣州包括赣州与赣州西；揭阳机场站不会替换成揭阳站，龙川西不会替换成龙川站。

## 快速开始

准备 **Python 3.11+** 和 Git。没有 Git 也可以点击仓库的 **Code → Download ZIP**，解压后在该文件夹打开终端，跳过下面前两行。

先运行 `python3 --version`（Windows 使用 `py -3 --version`）确认版本不低于 3.11；如果系统自带 Python 较旧，请安装新版并使用对应命令创建环境。

### macOS / Linux

```bash
git clone https://github.com/YouHanCheng6/personal_rail.git
cd personal_rail
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

### Windows（PowerShell）

```powershell
git clone https://github.com/YouHanCheng6/personal_rail.git
cd personal_rail
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

如果没有 `py` 命令，可将 `py -3` 替换为 `python`。以上命令直接使用虚拟环境中的 Python，无需激活脚本或修改 PowerShell 执行策略。

看到服务启动信息后，在浏览器打开 **[http://127.0.0.1:2036](http://127.0.0.1:2036)**。

这是运行在你电脑上的应用，该地址指向你自己的电脑。使用期间保持终端运行，按 **Ctrl+C** 退出。下次打开时，进入项目目录执行对应平台的最后一条启动命令即可，无需重复安装。

### 第一次查询

1. 选择出行方向和日期。
2. 选择席别取向，按需填写铁路预算或展开换乘条件。
3. 点击“查找并比较”，查看候选行程。
4. 切换排序，选择最多 3 个方案进行比较，展开详情核对来源。

## 接入大模型

这一步是可选的。查询、费用计算和排序由程序完成；模型用于在已有方案中进一步推荐。你可以使用支持 **OpenAI 兼容 Chat Completions 接口**的服务商。

### 1. 创建配置文件

在项目根目录复制 `.env.example`，将副本命名为 `.env`：

macOS / Linux：

```bash
cp .env.example .env
```

Windows PowerShell：

```powershell
Copy-Item .env.example .env
```

### 2. 填写连接信息

用文本编辑器打开 `.env`，填写以下三项。尖括号中的内容是占位说明，需要全部替换为服务商提供的实际值：

```dotenv
RAIL_MODEL_BASE_URL=<HTTPS接口基地址>
RAIL_MODEL_API_KEY=<你的API密钥>
RAIL_MODEL_NAME=<服务商提供的模型ID>
```

| 配置项 | 如何填写 |
| --- | --- |
| `RAIL_MODEL_BASE_URL` | API 基地址。例如服务商的完整调用地址是 `https://api.example.com/v1/chat/completions`，这里填 `https://api.example.com/v1`。此域名仅作格式示例。 |
| `RAIL_MODEL_API_KEY` | 你在服务商控制台创建的密钥。 |
| `RAIL_MODEL_NAME` | 服务商接口接受的模型 ID，按其文档原样填写。 |

接口需支持 HTTPS、Bearer 认证、`messages` 和 `max_completion_tokens` 参数，并能返回 JSON 文本。并非所有宣称兼容的服务都支持相同参数，请以服务商文档为准。

### 3. 重启并查询

停止正在运行的服务，重新执行启动命令，再查询一次。配置有效时，推荐区会显示模型分析结果。连接失败或返回内容不符合要求时，页面保留规则推荐，查询与比较仍可使用。

系统环境变量优先于 `.env`。密钥只供后端调用，`.env` 已加入 Git 忽略规则，请勿上传。调用模型可能产生服务商费用。

## 数据说明

行程数据来自去哪儿公开日期页，官方公告来自 12306 公开栏目。程序按路线和日期缓存行程 10 分钟，公告缓存 15 分钟；读取时检查访问策略和页面日期。来源不可用、格式改变或日期不匹配时，页面会提示，过期资料不会作为当前查询结果继续推荐。

- 日期选择目前按包含当天的 15 天窗口限制，具体起售时间以车站公告为准。
- 费用按各段所选席别的成人参考价加总，不包含市内交通、住宿、餐饮等费用。
- 舒适度和换乘风险是基于席别、时长及换乘安排的估计，实际出行请核对运营方信息。
- 模型只接收候选行程与排序偏好，不接收本地文件或账号信息；输出必须引用已有候选。

本项目用于行程规划，不提供账号登录、订票、候补或抢票功能。使用者应遵守数据来源的访问规则。

## 常见问题

**不配置模型能用吗？**  
能。查询、排序、筛选、方案对比、公告查看和导出都可以使用，推荐区采用程序计算的排序结果。

**为什么浏览器打不开？**  
确认启动终端没有关闭，并查看是否出现安装失败或端口占用错误。若提示 `Address already in use`，可能已有一个实例正在运行，可先直接访问页面。不要重复启动多个实例。

**为什么查不到行程？**  
检查日期、路线、预算和换乘条件，并查看页面提示。公开来源可能暂不可用或未提供符合条件的数据；无结果不等于当天没有列车。

**为什么模型没有生效？**  
检查 `.env` 是否位于项目根目录、文件名是否误写成 `.env.txt`，三个字段是否完整，基地址是否重复包含 `/chat/completions`。核对模型 ID、服务商额度及接口参数支持情况，修改后重启。

**其他人怎么使用？可以通过我的网址打开吗？**  
其他人可以克隆这个公开仓库，按上述步骤在自己的电脑上运行。默认的 `127.0.0.1` 地址仅在运行服务的电脑上可访问。当前版本没有多用户认证，不提供面向公网的部署配置。

**数据保存在哪里？**  
缓存与有限观察记录在 `personal_rail/.local/`，该目录不上传到 Git。项目不保存聊天记忆。

## 参与开发

欢迎通过 [Issues](https://github.com/YouHanCheng6/personal_rail/issues) 反馈问题或提出建议，通过 Pull Request 提交改进。提交问题时提供系统、Python 版本、复现步骤和已脱敏的错误信息；不要附上 `.env` 或 API 密钥。

开发环境、测试命令与贡献约定见 [CONTRIBUTING.md](CONTRIBUTING.md)。

```text

├── planner.py   # 行程比较和评分规则
├── service.py   # 数据采集与模型适配
├── news.py      # 官方公告解析
├── static/      # 无需构建的网页与资源
└── tests/       # 自动化测试
run.py           # 启动入口
.env.example     # 模型配置模板
```
