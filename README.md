# 沿线 · 个人铁路行程比较

![晨雾列车主题图](personal_rail/static/images/morning-train.webp)

轻量本地网页：比较时刻、席别参考价、换乘风险与预计舒适度，可选接入大模型帮助取舍。上图为生成的主题插画，不是实际班次或车型照片。无需 DeerFlow、铁路账号或前端构建工具。

## 快速开始

需要 Python 3.11 或更新版本。下载或克隆本仓库，在仓库根目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

Windows 使用 `python -m venv .venv`，在 PowerShell 中通过 `.venv\Scripts\Activate.ps1` 激活环境。

打开 http://127.0.0.1:2036 ，保持终端运行；按 Ctrl+C 停止。默认只监听本机，不向局域网或互联网开放。未配置模型时仍可查询和比较，推荐使用规则回退。

## 配置大模型（可选）

复制 `.env.example` 为仓库根目录的 `.env`，填写三个字段：

| 变量 | 内容 |
| --- | --- |
| RAIL_MODEL_BASE_URL | 服务商提供的 HTTPS OpenAI 兼容接口基地址；按服务商要求包含 `/v1`，不要填写 `/chat/completions` |
| RAIL_MODEL_API_KEY | 你自己的 API 密钥 |
| RAIL_MODEL_NAME | 服务商实际支持的模型 ID |

程序向基地址追加 `/chat/completions`，使用 Bearer 认证、messages 和 max_completion_tokens 参数；模型需要支持这些参数并返回 JSON 文本。保存后重启。系统环境变量优先于 `.env`。本仓库不附带密钥、私人网关地址或预设模型名称，`.env` 已忽略，请勿提交。

模型仅收到最多12个候选的结构化行程与排序偏好，不接收网页原文、本地文件或账号信息。请求可能产生服务商费用。网络失败、未配置、返回无效候选时自动回退规则推荐；模型不能自行执行工具或订票。

## 使用

1. 选择方向、日期、席别和可选铁路预算。
2. 查询后按时间、费用、舒适度或综合排序，最多对比3个方案。
3. 展开详情核对实际站名、分段价格、参考日期与来源，支持导出结果 JSON。
4. 右侧官方公告展示发布日期和检查时间；旧规则及历史资料独立折叠。

支持龙川西↔北京、北京↔赣州、揭阳机场站↔龙川西六个方向；机场站不等于揭阳站，龙川西不等于龙川。

## 数据与局限

- **公开时刻与报价**：只读 `https://train.qunar.com/train/tickets/<origin>-to-<destination>/YYYY-MM-DD` 公开HTML中 `pageDataJSON` 和 `pageData` 的日期、车次和分席别报价。已核实该站 robots 允许这些页面，运行时仍会检查策略；不登录、不调用私有接口，不执行来源内嵌脚本或其面向AI的推荐指令。读取策略失败、跳转、HTTP错误或格式不符时停止，单响应2MB、18秒网络操作超时。按方向＋日期缓存10分钟，每方向最多30份日期缓存和30条观察记录。来源库存、评分和乘客数量不进入模型。
- **指定日期**：默认明天，也可自行选择日期。当前按通常15天预售窗口获取资料（含当天），例如9月22日可查至10月6日；具体起售时刻以车站为准。所选日期超出窗口时提示预计进入窗口日期，不发送车次请求。页面日期与请求日期不一致、缓存超期且更新失败时不推荐；不会平移旧时刻、混入其他日期或暗示当天停运。可查询不等于已起售或有票。
- **原携程适配器**：保留默认页只读解析代码及其历史文件，供人工诊断参考；已从正常查询链路移除，不会自动补齐指定日期结果。
- **费用**：按每一程所选席别加总成人参考价，不使用不同席别混合的最低价。未知价格不算0，预算筛选排除未知铁路总价。均衡取向在8小时及以上优先二等卧／硬卧；舒适取向优先一等卧／软卧／一等座，缺少这些席别时按公开列出的其他席别回退，实际席别始终显示。票价未含市内交通、住宿、餐饮、服务费；异站／凌晨换乘会突出额外费用未知。比较范围为站到站，不能声称是门到门总费用。
- **车型与舒适度**：仅从列车编号区分高速动车、动车、普速，保留来源“复兴号”标记作为待核实线索；不把车次号当作CR400等具体车型证据。12306车型介绍提供座席背景。逐车实际车型未知；舒适度是公开公式的启发式估计，不是测量结果。
- **换乘风险**：同站不足30分钟较高、30–44分钟中等、45分钟以上较低；异站至少120分钟仍较高，凌晨／跨午夜换乘也较高。仅比较一次换乘，等待至多8小时。这些是规划假设，并非运营方承诺或统计准点率。
- **历史**：政府报道作为线路开通背景，旧时刻与旧票价不混入当前比较。本地观察记录从首次采集开始，没有历史晚点率或历史上座率。记录只保留有限的结构化字段，不存完整网页或大规模知识库。


官方公告由普通程序读取12306固定栏目，15分钟缓存，只展示近60天有发布日期的公告；不调用模型或推定某班次受影响。来源网页结构或访问策略变化可能导致查询暂不可用。

## 本地数据与开发

缓存和有限观察记录保存在 `personal_rail/.local/`，不提交到仓库。没有聊天记忆、账号登录、候补或抢票功能。

```bash
pip install -r requirements-dev.txt
python -m pytest personal_rail/tests -q
ruff check personal_rail run.py
```

`dated.py` 处理日期页，`planner.py` 负责比较规则，`service.py` 负责采集与模型调用，`news.py` 处理公告，`app.py` 提供本机 API，`static/` 为原生网页。测试数据为合成样例，不用于生产推荐。字体许可见 `personal_rail/static/fonts/OFL.txt`。
